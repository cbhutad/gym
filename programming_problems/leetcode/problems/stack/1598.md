# 1598. Log Crawler Folder

## My Solution

``` java

class Solution {
    public int minOperations(String[] logs) {
        LinkedList<String> stack = new LinkedList<>();

        for (String log : logs) {
            String[] parts = log.split("/");
            
            if (parts[0].equals("..") && !stack.isEmpty()) {
                stack.removeFirst();
            } else if (!parts[0].equals(".") && !parts[0].equals("..")) {
                stack.addFirst(parts[0]);
            }
        }

        return stack.size();
    }
}
```
